## 4. 백(白) 무구 10 — 해원·천도

> 공통: 무구 VFX는 **한지 `#e9dcc0` 반투명 50% + 재질 패턴**(방울·장구 = 음파 링 선, 부채 = 바람결 선, 넋전·지전·길베 = 종이결, 쑥물 = 물결, 소금 = 결정 점묘, 명두 = 놋쇠빛 테두리의 한지 광선, 오방기 = 오색 가장자리 + 한지 바탕). 순백 `#f2ece0`은 풀릴 기색 외곽선·영가·해원 빛기둥 전용(D5, 리뷰 R13). 해원 시 흰 빛 수직 상승 + "딸랑"(캐논 6.1). 해금 재화 공덕(신당, 동사 '봉헌'). **백 무구는 풀릴 기색 적을 밀어내지 않는다**(넉백 0, 2.7). 풀릴 기색 대상 피해 ×`stat_puri`(기본 3.0). 의례 기준값은 레벨에 따라 2.8 표.
> 0:30에 무당의 백 시작 무구가 강제 지급된다(캐논 3.4). 단골은 시작부터 백 무구 2개다.

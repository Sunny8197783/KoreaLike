## 5. 결합(양면 무구) 6

> 공통 규칙(캐논 3.2.12): 지정된 적 진화형 + 백 진화형을 **둘 다** 보유한 상태에서 상자를 열면 두 무구가 양면 무구 1개로 합쳐지고 **슬롯 1개가 반환**된다. 양면 무구는 타격마다 대상 상태를 읽어 색을 바꾼다(2.2): 풀릴 기색 → 백(`white_dmg × stat_puri`, 해원), 그 외 → 적(`dmg`, 결단 판정, 매듭 잠금 적용). 결합은 **제3의 색이 아니다**(캐논 P1 금지 사항). VFX는 타격마다 적/백이 바뀌고, 무구 아이콘은 반으로 나뉜 적·백 테두리.
> 결합 무구의 의례 기준값 = 40(2.8). 결합 무구는 백 무구로도 센다(영가 오라·길닦음 계산에 포함).

### 6.2 진화 조건 · 판정 순서

**상자 보상 정의 (v0.9.1 단일안, 리뷰 R4).** 이전 판은 "상자 = 진화·결합 1건, 아니면 일반 보상(08)"이라 상자가 강화를 주는지 정하지 않았다. 09처럼 엽전만 주면 진화가 13분 이후로 밀리고(6.3 비교 열), 02 18.2처럼 슬롯마다 진화하면 상자 하나에서 진화가 여러 건 터진다. 아래 하나로 고정한다.

```
on_box_open(box):                          # box_gilhyung(퇴치 드롭) 또는 box_neokham(해원 드롭)
    n = grade_roll(box)                    # 1 / 3 / 5 (등급 확률은 05 12.1 · 02 18.1 정본, 중간보스 최소 3)
    transformed = false
    repeat n times:
        if not transformed:
            u = oldest_completed([u for u in UNIONS if owns(u.parts[0]) and owns(u.parts[1])])
            if u: do_union(u); transformed = true; continue                 # ① 결합 우선
            w = earliest_lv8([w for w in owned_weapons if w.level == 8
                              and owns_passive(w.pair_passive, min_lv=1)])
            if w: do_evolve(w); transformed = true; continue                # ② 가장 먼저 Lv8이 된 무구
        w = highest_level([w for w in owned_weapons if w.level < 8])        # ③ 최고 레벨 무구 +1 (동률은 상자 RNG)
        if w: w.level += 1; continue
        p = highest_level([p for p in owned_passives if p.level < 5])       # ④ 최고 레벨 패시브 +1
        if p: p.level += 1; continue
        grant(yeopjeon = 10 × 시주)                                         # ⑤ 모두 최대: 엽전 (02 18.2)
    always: 확정 부가 — 길흉 상자 엽전 +3 × 시주 / 넋함 사연 조각 판정 (02 18.1, 09 2.4)
    # 결합·진화는 상자당 합쳐서 1건. 남은 후보는 다음 상자에서.
```

## 7. DPS 추정

### 7.1 방법

```
DPS_보스 = 반경 2u 단일 대상(모든 투사체·갈래가 맞는다고 가정)에 대한 초당 피해
DPS_군집 = 기준 밀도 ρ = 0.30마리/u² 무리 속에서 1회 발동 기대 타격 수 × 피해 / 주기
  원형(반경 r)       : min(40, ρ·π·r²)
  부채꼴(r, θ)       : min(40, ρ·π·r²·θ/360)
  직선(길이 L, 폭 w) : min(관통, 40, ρ·L·(w + 0.6))     # 0.6 = 잡귀 지름
  고리 띠(r)         : min(40, ρ·2π·r·0.8)
  장판(틱)           : 원형 × (지속/0.5)
  공전               : 넋전당 초당 min(ρ·ω·r·1.1, 4)
  함정               : 마름쇠 수 × 내구 × 실현율 0.45 (동시 상한 반영)
  다중 장판 중복 보정: 0.7 (같은 무구 장판을 여러 개 던질 때 대상이 겹침)
공통: 신빨 100%, 장단 100%, 결단 5%(적, 기대값 ×1.05), 피해 변동 없음, 위상 이월(05 3.2.2a)로 평균 주기 = 쿨다운
```

- **양자화 전제:** 이 표는 05 3.2.2a 위상 이월을 전제로 한다. 02 10.2의 '다음 그리드로 올림'으로 구현하면 무구에 따라 −0~25%가 된다(2.4.2). 구현이 05 방식이 아니면 이 표 전체가 과대평가다.

- **이 값은 "용량"이다.** 오버킬(한보다 큰 피해)과 빈 공간을 빼지 않았다. 실제 처치 속도는 스폰 유입이 상한이다(7.4).
- 진화형·결합의 부가 효과(연쇄 해원, 판결 상자, 버프, 회복, 공포 증폭, 살기 정화)는 DPS에 넣지 않았다. 지원형 무구(호작도·소금·오방기·지전 진화)가 표에서 낮아 보이는 것은 의도다.
- 계산 코드는 `data/weapons.json`의 `est_dps_*`와 같은 모델이다. 09 섹션은 이 값을 출발점으로 봇 1,000런 시뮬레이션에서 실측 DPS 점유율로 대체한다.

### 8.5 적(퇴치) 쪽 능동 루프와 무구 연동 `[가정: 02 채택 시, 리뷰 R10]`

리뷰 R10은 해원 쪽에만 서사·해금·콤보 보상이 몰려 "해원이 정답"으로 학습된다고 지적했다. 해원/퇴치 보상 구조 자체는 02·09·11 소관이고, 04는 **무구 쪽에서 적 플레이를 '능동적인 선택'으로 만드는 연동 규칙**만 준비한다. 02가 '살 거두기 → 벽사 기세' 루프를 채택하면 아래를 그대로 쓴다.

| 연동 | 규칙 (04 소유 부분) | 설계 의도 |
|---|---|---|
| 벽사 오름 중 한 파열 충격파 | 벽사 오름(8초) 동안 **적 무구 1타로 일어난 한 파열**마다 그 위치에 소형 충격파: 반경 1.5u, 피해 = 그 타격 최종 피해 × 0.5(적 색, 결단 판정 없음). 충격파로 일어난 파열은 충격파를 다시 만들지 않는다(연쇄 1단). 화신·보스에게는 0 | 2.3 파열형 무구(작두·편곤·사인참사검)를 고른 이유가 '퇴치 쾌감'으로 돌아오게 한다. 연쇄 1단으로 투사체·히트 예산(2.6)을 지킨다 |
| 파열형 우대 | 충격파 반경은 그 무구의 k 성향과 무관하게 고정. 대신 **생산자 무구(장창·철질려·호작도)의 결단타 퇴치도 충격파를 일으킨다** | 생산자 무구로도 벽사 오름을 쓸 수 있게(빌드 다양성) |
| 원귀 상자 | 원귀 퇴치 상자 등급 +1 확정(6.2, 05·02에 요청) | 원귀 회귀를 '처벌'이 아니라 '진화 기회'로 읽히게 |
| 살 알갱이 vs 소금 | 소금 계열은 살 알갱이를 '거두지 않고 지운다'(기세 0). 벽사 기세는 무당이 직접 밟은 알갱이만 오른다 | 소금(백)과 벽사 기세(적)가 같은 자원을 두고 경쟁하는 결정을 만든다 |

### A8. 장단 폭주 (신명 · 쿨다운)

| 항목 | 내용 |
|---|---|
| 핵심 무구 | 장구 → 합장단, 장창 → 파진창, 방울 |
| 보조 무구 | 각궁, 부채 |
| 패시브 우선 | 궁채 > 미투리 > 초혼 적삼 > 경면주사 > 백지술 > 오방끈 |

| 해원 비율 목표 | 50~70% |
| 핵심 수치 | 궁채 Lv5(−30%) + 장군 위엄(−10%) + 청기(−10%p) = 장단 50%. 신명 오름 중 하한 25%까지 열림 → 15초 동안 발사 속도 ×2 |

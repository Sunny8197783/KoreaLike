## 1.2 넋길 스탯이 VS와 다른 3지점 (색다름의 근거)

### (1) 신빨 딜레마 — 강해질수록 풀어 줄 틈이 좁아진다

VS에서 Might는 순수 이득이다. 넋길에서는 적 무구 한 방이 대상의 남은 한보다 크면 **한 파열 = 퇴치**가 된다(캐논 3.2.2 (a)). 그래서 신빨이 오르면 풀릴 기색 구간(한 35%~0%)을 건너뛰는 타격이 늘고, 그만큼 살 알갱이와 살기가 쌓인다. 캐논 3.2.2 설계 의도("후반 고신빨 적 빌드는 한 파열로 퇴치가 늘어 살기가 자연 상승")가 바로 이 스탯 구조에서 나온다. 수식은 5.4절에 있다.

- **플레이어가 느끼는 선택:** "신빨을 더 올릴까, 아니면 풀이·결단 0 빌드로 해원 창을 지킬까."
- **UI:** 신빨 툴팁에 "적 무구 단타가 한의 50%를 넘으면 풀릴 틈 없이 깨질 수 있다"는 경고 한 줄을 넣는다.

### (2) 고리 기하학 — 이동 스탯이 의식 스탯이다

길닦음 고리는 무당이 4초(`stat_gilbe`) 동안 걸은 궤적으로 닫는다. 따라서 그릴 수 있는 **최대 면적은 이동속도 × 길베 시간으로 정해진다**(4.2절).

- 기본값(도무 100% = 4.0유닛/s, 길베 4.0초)이면 최대 면적은 약 24타일²다. 오방 만다라 도량(60타일²)은 기본 스탯으로는 **불가능**하다.
- 그래서 미투리(도무), 길베 연장, 신명 오름(길베 ×2)이 고리 빌드의 핵심 투자처가 된다.
- VS의 Move Speed는 생존 스탯이다. 넋길의 도무는 생존 스탯이면서 **의식 규모 스탯**이다.

### (3) 색 기울기(Tilt) 표시 [NEW]

모든 스탯과 패시브에 `tilt` 값을 붙인다: `red`(퇴치 쪽), `white`(해원 쪽), `neutral`. 점지 카드 모서리에 붉은 점·흰 점·회색 점을 찍고, 일시정지 스탯 패널 상단에 **빌드 기울기 바(`ui_build_tilt`) [NEW]**를 표시한다(14.3절).

- 도덕 표기는 쓰지 않는다(캐논 P3). 바의 양끝 이름은 "깎기 ← → 풀기"다.

# 2. 스탯 계산 파이프라인

## 2.1 수정자(modifier) 연산 5종

모든 스탯 변화는 아래 5개 연산 중 하나다.

| 연산 `op` | 의미 | 예 | 들어가는 자리 |
|---|---|---|---|
| `flat` | 기본치에 고정값을 더한다 | 신복 +1, 신장 수 +1, 행렬 +4, 길베 +0.5초, 점괘 +10, 결단 +1%p | ① 고정 합 |
| `add_pct` | 가산 % 버킷에 더한다 | 신빨 +8%, 도무 +8%, 장단 −6% | ② 가산 % 합 |
| `mult` | 곱연산(지정 출처만) | 미완 빙의 ×0.7, 살 맺힘 단 정기 ×0.85, 이동 감속 ×0.85 | ③ 곱연산 |
| `floor_override` | 하한을 일시 변경 | 신명 오름 중 장단 하한 0.40 → 0.25 | ④ clamp 단계 |
| `cap_override` | 상한을 일시 변경 | (v1 사용처 없음, 예약) | ④ clamp 단계 |

## 2.2 공식

```
최종값 = clamp( (base + Σ flat) × (1 + Σ add_pct) × Π mult , floor, cap )
```

- `base`: 캐논 4.5 기본값 (무당 고유 보정은 `flat` 또는 `add_pct`로 별도 표기. 13장)
- `Σ add_pct`가 −1 이하가 되면 0으로 처리한다(음수 스탯 금지).
- **정수 스탯**(신장 수, 행렬, 명줄, 다시 묻기, 물림, 금기)은 clamp 뒤 `floor()`를 적용한다.
- **장단**은 감소형 스탯이다. `base = 1.0`, 감소는 음수 `add_pct`. 예: 궁채 Lv5(−30%) + 장군 위엄(−10%) → 1 − 0.40 = 0.60.
- **풀이**는 배율형 스탯이다. `base = 3.0`, 증가는 `flat`(×단위). 예: 권능 +0.5 → ×3.5.
- **결단, 접신 회피**는 확률형이다. `base`는 확률(0.05 / 0.00), 증가는 `flat`(%p). 감쇠 없이 더한 뒤 상한으로 자른다.

**설계 의도:** 공식 하나로 25종을 모두 처리한다. 예외는 위 4줄뿐이라 툴팁 계산기와 서버 검증(오늘의 굿판 순위표)이 같은 함수를 쓸 수 있다.

## 2.5 재계산 시점 (이벤트 주도)

- 스탯은 **매 프레임 계산하지 않는다.** 수정자가 추가·제거·레벨 변경될 때만 해당 스탯을 다시 계산하고 캐시한다.
- 트리거: 점지 선택, 진화·결합, 빙의, 시한 버프 시작·만료, 명줄 발동, 모드 적용, 신명 오름 시작·종료.
- `TEMP` 수정자는 만료 시각을 들고 있다. 매 0.1초 만료 검사 큐(최소 힙)로 처리한다.
- 스탯이 바뀌면 `stat_changed(stat_id, old, new)` 이벤트를 쏘고, HUD와 무구 컨트롤러가 구독한다. → 참조: 11-ux-ui-hud (폴링 금지, 이벤트 주도 HUD)

**설계 의도:** 적 400 + 영가 60 + 스팀덱 60fps 성능 목표(캐논 8.3 14번)를 지키려면 스탯 계산이 프레임 비용에 들어가면 안 된다.

#### 3.2.2a 박 그리드 양자화 + 위상 이월 — **단일 정본** [NEW 해석]

> **소유 (리뷰 대응 R-01):** 무구 발동 양자화 규칙은 이 절 하나만 정본이다. 02 10.2의 `ceil` 공식과 실효 주기 표, 04 2.4.2의 잔여 이월 의사코드, `combat_core.json` `jangdan.quantize_rule`, `weapons.json` `globals.quantization`은 이 절을 참조하도록 고친다(→ 20장 요청 목록). 구현은 이 절의 의사코드 하나로 한다.

**왜 캐논 문구를 그대로 쓰지 않는가.** 캐논 3.2.8은 "쿨다운이 끝난 뒤 가장 가까운 다음 그리드에 발동"이다. 문구대로 `P = ceil(cd / g) × g`로 구현하면 다음 손해가 생긴다.

| 사례 | 명목 간격 | `ceil` 실효 간격 | DPS 손실 |
|---|---|---|---|
| 쿨 1.0초 무구, 중중모리(g 0.316) | 1.00초 | 1.26초 | −21% |
| 방울 Lv4 0.52초, 진양조(g 0.333) | 0.52초 | 0.667초 | −22% |
| 궁채 Lv1(−6%), 쿨 1.5초, 중모리(g 0.375) | 1.41초 | 1.50초 (Lv0과 같음) | 스탯 효과 0 = **죽은 픽** |

또 장단이 같아도 거리가 바뀔 때마다 실효 주기가 들쭉날쭉해서(1.00 → 1.26 → 1.12…) "장단이 빨라질수록 강해진다"는 설명도 성립하지 않는다. 그래서 아래처럼 **이상 발동 시각(위상)을 이월**한다.

```
입력: base_cd     무구 레벨 표의 기본 쿨 (04 / weapons.json)
      min_period  무구별 최소 주기 (04 2.6)
      j           stat_jangdan,  F = 0.40 (신명 오름 중 0.25)
      g           현재 그리드 길이(초) = 거리 BPM과 흥 단계로 정해짐. 박 머리 무구(장구·합장단)는 1박
cd = max(min_period, base_cd × max(F, j))

on_acquire(t):                    # 무구 획득·진화·결합 직후
  ideal_t = t                     # 다음 그리드 틱에 첫 발동
  last_fire_t = −∞

on_grid_tick(t):                  # 그리드 틱마다 호출 (게임 시간, 점지·일시정지 중 정지)
  if t + ε >= ideal_t and t >= last_fire_t + g:     # 최소 간격 1그리드
     fire()
     last_fire_t = t
     ideal_t = ideal_t + cd       # ★ 실제 발동 시각이 아니라 이상 시각에 더한다 (위상 이월)
     if t − ideal_t > g:          # 밀린 위상이 1그리드를 넘으면 (템포 전환·cd < g)
        ideal_t = t + cd          #   넘친 이월은 버린다 (몰아 쏘기 방지)

on_cd_change(cd_old, cd_new):     # 장단 스탯 변화, 신명 오름 시작·종료, 무구 레벨업
  ideal_t = last_fire_t + (ideal_t − last_fire_t) × cd_new / cd_old
```

- **결과:** 각 발동 간격은 항상 그리드의 정수배다(예: 3, 3, 2, 3, 3그리드…). 캐논 G3의 "이산 단계" 감각과 캐논 3.2.8의 "판정 없음, 박에만 발동"은 그대로다. **평균 간격 = `max(cd, g)`** 이다. `cd ≥ g`이면 평균 간격이 정확히 `cd`라서 스탯이 표시한 만큼 DPS가 오른다.
- **04 잔여 이월과의 관계:** 04 2.4.2의 `acc += g; if acc ≥ P: fire; acc −= P; acc = min(acc, P + g)`는 이 절과 같은 발동열을 만든다(밀림 상한 1그리드). 두 의사코드가 공존하면 구현이 갈라지므로 04는 이 절 참조로 대체한다. 04가 위 방식으로 계산한 `est_dps`는 그대로 유효하다(`ceil` 구현 대비 과대평가 문제는 이 규칙을 채택하면 사라진다).
- **최소 간격 1그리드 (그리드 미만 발동은 버림):** `cd < g`이면 매 그리드 1회로 제한하고 남는 속도는 버린다. 손실률은 `1 − cd / g`다. 기본 쿨 0.6초 이상인 무구는 평시 하한(40%)에서도 대부분 거리에서 `cd ≥ g`다. **예외는 오라형 방울 계열**(방울 Lv4~8 0.52초, 천음방울 0.5초, `min_period` 0.25초)이다.

  | 방울 Lv4 (0.52초) | 장단 100% | 60% (0.312) | 40% (0.25, min_period) | 신명 오름 28.5% (0.25) |
  |---|---|---|---|---|
  | 진양조 g 0.333 | 손실 0 | 평균 0.333 (−6%) | 평균 0.333 (−25%) | 평균 0.333 (−25%) |
  | 중모리 g 0.375 | 0 | 평균 0.375 (−17%) | 평균 0.375 (−33%) | 평균 0.375 (−33%) |

#### 3.2.2b 신명 오름의 장단 효과 — R3 채택 (리뷰 대응 R-06, R-14)

캐논 3.2.7의 "장단 하한 25%로 일시 확장"만 두면 효과가 없다. 장단 감소 출처를 모두 더해도 하한 40%에 닿지 않기 때문이다.

| 출처 | 장단 감소 |
|---|---|
| 궁채 Lv5 | −30% |
| 장군 위엄 (만신 ×1.15) | −10% (−11.5%) |
| 군웅 행진 Lv3 (영가 24 필요) | −12% |
| 계보도 | −3% |
| **합계 (최대)** | **−56.5% → 장단 43.5%** |

평시 하한 40%에도 못 미치므로 25% 하한은 어떤 빌드에서도 작동하지 않는다. 그래서 05는 02의 CANON-REQUEST R3를 **채택**한다: **신명 오름 15초 동안 `stat_jangdan`에 −0.15를 가산(`TEMP` add_pct)하고, 하한을 25%로 내린다.** 데이터 값은 `stats.json constants.sinmyeong_oreum_jangdan_bonus = −0.15`이며, `combat_core.json sinmyeong.jangdan_bonus`도 −0.15다(캐논 v1.2 D-17 승인, 02 반영 확인).

| 빌드 장단 (평시) | 오름 중 | 발사 속도 변화 |
|---|---|---|
| 100% (투자 0) | 85% | +17.6% |
| 70% | 55% | +27% |
| 43.5% (최대) | 28.5% | +53% |
| 43.5% + 장단 권능 1개(−3.5% 이상) | 25% (하한) | +74% |

- **곱연산 ×0.75(M7 신설)를 택하지 않은 이유:** ① 곱연산 출처를 닫힌 목록(2.3)으로 최소화한다는 원칙 S2. ② 두 데이터 파일이 이미 −0.15를 갖고 있어 바뀌는 곳이 `combat_core`의 스위치 하나뿐이다. ③ ×0.75면 최대 빌드도 0.435 × 0.75 = 32.6%에 그쳐 캐논 25% 하한이 더 멀어진다. 가산이면 장단 투자 빌드가 하한에 닿을 길이 생긴다.
- **발동 빈도·투사체 상한 재검증:** 20분 거리 구간의 그리드 최소값은 0.167초(자진모리 1/3박·뒷전 최고조 1/2박)이고, 보스전 전체에서는 살형 보스 엇모리 소박 0.150초(12 2.2)가 가장 짧다. 그래서 무구 하나는 **초당 최대 6.7회**를 넘지 못한다. 상한 추정은 6무구 × 6.7회/s × (1 + 신장 수 상한 10)발 × 평균 체공 1.0초 ≈ 440발로, 전역 소프트 상한 600(04 2.6, `combat_core.caps.player_projectiles`) 아래다. 실제로는 무구별 동시 활성 상한(지전 60, 철질려 60, 각궁 40, 넋전 16, 신칼·명두 12 …)이 먼저 걸려 상위 6종 합이 약 200발이다. 600을 넘는 경우에도 04의 탄 병합 규칙이 DPS를 보존한다. **결론: R3는 성능 예산 안에서 안전하다.**
- **[CANON-REQUEST R-06: 3.2.7 보강] → 캐논 v1.2 D-17 승인.** "신명 오름: 장단 −15%p 일시 가산 + 하한 25%로 일시 확장." 사유: 하한 확장만으로는 피버의 장단 효과가 0이다.

최종 피해 = D0 × 신빨 × (1 + Σ조건부) × 상태 배율 × 적 저항
```

| 단계 | 기호 | 정의 | 출처 / 상·하한 |
|---|---|---|---|
| A | `D0` | 무구·권능의 레벨별 기본 피해 | → 참조: 04-weapons-evolution, 06-deities-possession |
| B | `신빨` | `stat_sinppal` (1.0 ~ 10.0) | 3.2.1 |
| C | `Σ조건부` | 조건이 맞을 때만 더하는 가산 % 버킷 | 상한 +300% |
| D | `상태 배율` | 풀이 × 결단타 × (1 + 받는 피해 증가) | 5.2 D |
| E | `적 저항` | 적 데이터의 색별 받는 피해 배율 `dmg_taken.red / .white` (기본 1.0) | → 참조: 07-enemies-bosses |

- **분산 없음.** 같은 상황의 같은 타격은 항상 같은 피해다(원칙 S5).
- 내부 계산은 부동소수점이고 화면 숫자만 반올림한다(최소 1 표시).
- 적 한(HP)도 부동소수점이다.

## 5.2 버킷 상세

### B. 신빨
모든 피해원에 곱한다: 적 무구, 백 무구, 영가 넋두리 오라, 길닦음 효과 2(고리 안 백 피해), 신령 권능 피해, 결합 무구.

### C. 조건부 버킷 (가산 합, 상한 +300%)

| 조건 키 `cond` | 예 | 비고 |
|---|---|---|
| `color_red` / `color_white` | 단골 백 피해 +25% | 색 전체 피해 증가 |
| `weapon_form_melee` / `_projectile` / `_zone` / `_aura` | 범 위엄 "적 무구 근접 신빨 +40%" → `color_red ∧ melee` | 캐논 표기 "근접 신빨"은 이 버킷이다(전역 신빨 아님) |
| `target_species:<enm_id>` | 벽사록 종별 +3/6/10% | **적 무구에만 적용 [NEW 해석]**. 퇴치 루트의 보상이므로 퇴치 색에 묶는다. → 참조: 09-meta-economy |
| `target_tier:elite+` | 사인참사검 정예·보스 추가 피해 | `WEAPON` 범주 |
| `weapon_self` | 무구 자체 레벨업 보너스("피해 +10%") | 그 무구에만 |

- 산군포효도의 "공포 대상 받는 피해 +20%"는 C가 아니라 **D단계의 받는 피해 증가**로 분류한다.
- **설계 의도:** 신빨(B)과 조건부(C)를 따로 곱해서 "전역 성장"과 "특화 성장"이 서로를 키우게 한다. C 상한 +300%로 특화 중첩 폭주를 막는다.

### D. 상태 배율 (곱연산 M5·M6)

```
상태 배율 = P × K × V

P (풀이)    = stat_puri       피해 색이 백이고 대상이 풀릴 기색일 때
            = 1.0             그 외
K (결단타)  = 2.0             피해 색이 적, 결단 판정 성공, 대상이 "풀릴 기색 일반 잡귀"가 아닐 때
            = 즉시 퇴치        피해 색이 적, 결단 판정 성공, 대상이 풀릴 기색 일반 잡귀일 때
            = 1.0             그 외
V (취약)    = 1 + min(0.5, Σ받는 피해 증가 디버프)
```

- 받는 피해 증가 디버프(공포 +20% 등)는 대상에 붙는 상태다. 여러 개면 더하고 +50%에서 자른다.

### E. 적 저항
- 적 데이터에 `dmg_taken: {red: 1.0, white: 1.0}`을 둔다. 예: 불가사리 `red: 0.5`(07 문서가 확정), 한형 보스 매듭 해제 전 `red: 0.25`.
- 특수 흡수(불가사리가 적 투사체를 먹고 커짐, 어둑시니가 적 피해를 받으면 커짐)는 피해 공식 밖의 **적 반응 규칙**이다. → 참조: 07-enemies-bosses, 캐논 3.2.9

## 5.3 처치 판정 (캐논 3.2.2를 타격 단위 의사코드로)

```
apply_hit(target, hit):                    # hit = {color, damage(5.1 결과), crit(bool), source}
  r_before = target.han / target.han_max
  is_minor = (target.tier == normal)       # 일반 잡귀만 매듭 잠금 대상

  if hit.color == red:
      if hit.crit and is_minor and target.pullil:        # (b) 결단타
          target.han = 0;  return finish(target, toechi, gyeoldan)
      new_han = target.han - hit.damage
      if is_minor and target.pullil:                     # 매듭 잠금
          new_han = max(new_han, 1.0)
      if new_han <= 0:
          if is_minor and r_before > pullil_threshold:   # (a) 한 파열
              return finish(target, toechi, han_pa)
          if not is_minor:                               # (c) 정예 이상
              return finish(target, toechi, elite_last)
      target.han = new_han

  else:  # white (백 무구, 영가 오라, 길닦음, 결합 무구 백 모드, 백 권능)
      target.han -= hit.damage
      if target.han <= 0:
          return finish(target, haewon, hit.source)      # 풀릴 기색 여부와 무관

  # 상태 전이
  if not target.pullil and target.han / target.han_max <= pullil_threshold:   # 기본 0.35, 살 맺힘 단 0.25
      enter_pullil(target)       # 얼굴 교체, 백 외곽선, 이속 ×0.7, 타이머 12초(2회차 8초)
```

**같은 프레임 동시 타격 처리 순서 [NEW]:** ① 길닦음 판정 → ② 백 무구 → ③ 영가 넋두리 오라 → ④ 적 무구. 같은 순서 안에서는 무구 슬롯 번호순이다.
- **설계 의도:** 결정론(오늘의 굿판 시드 재현)을 보장한다. 백과 적이 같은 프레임에 맞으면 "막타 색"이 프레임 순서라는 우연에 달린다. 그 우연을 핵심 동사(풂) 쪽으로 정해 둔다.

**판정 모서리 사례:**

| 상황 | 결과 | 근거 |
|---|---|---|
| 한 40% 잡귀에 적 피해 50% | 한 파열 → 퇴치 | (a) |
| 한 40% 잡귀에 적 피해 30% | 한 10% → 풀릴 기색 진입 | 상태 전이 |
| 풀릴 기색 잡귀(한 20%)에 적 피해 999 | 한 1에서 멈춤 | 매듭 잠금 |
| 풀릴 기색 잡귀에 적 결단타 | 즉시 퇴치 | (b) |
| 한 100% 잡귀에 백 피해 120% | 해원 (풀릴 기색을 거치지 않아도) | 캐논 3.2.2 해원 정의 |
| 정예(한 10%)에 적 피해 | 퇴치 | (c), 정예는 매듭 잠금 없음 |
| 풀릴 기색 정예에 백 피해 ×풀이 | 해원 → 넋함 | 정예도 풀릴 기색 상태(백 ×3, 감속)는 적용된다 |
| 결합 무구가 풀릴 기색 잡귀 타격 | 백 모드로 피해(×풀이), 결단 판정 없음 | 캐논 3.2.12 |
| 적 장판 틱이 한 36% → −2% | 한 파열 → 퇴치 | 틱도 단일 타격 |

## 5.4 신빨 딜레마 — 한 파열 확률 모델

적 무구 단타 피해를 대상 최대 한으로 나눈 값을 `x`라 하자.

**(1) 단일 무구가 만피 대상을 혼자 때리는 결정론 경우:**

| x 구간 | 결과 | 설명 |
|---|---|---|
| x < 0.35 | 항상 풀릴 기색 | 보폭이 창(35%)보다 좁아 반드시 창 안에 떨어진다 |
| 0.35 ≤ x < 0.50 | 풀릴 기색 | 2타째에 (0, 0.30] 구간에 떨어진다 |
| 0.50 ≤ x < 0.65 | **한 파열** | 1타 후 (0.35, 0.50], 2타째에 0 이하 |
| 0.65 ≤ x < 1.00 | 풀릴 기색 | 1타째에 (0, 0.35]로 바로 진입 |
| x ≥ 1.00 | **한 파열** | 한 방 |

**(2) 여러 출처가 섞여 위상이 무작위인 실전 근사:**
```
P(한 파열 | x) ≈ 0                 (x ≤ 0.35)
              ≈ 1 − 0.35 / x       (0.35 < x < 1)
              = 1                  (x ≥ 1, 만피 기준)
```

| x | 0.2 | 0.35 | 0.5 | 0.7 | 0.9 | 1.0+ |
|---|---|---|---|---|---|---|
| P(파열) | 0% | 0% | 30% | 50% | 61% | 100% |

- **밸런스 함의:** 적 무구 피해 성장(무구 레벨 × 신빨)이 일반 잡귀 한 성장(시간 + 살기)보다 빠르면 x가 커지고 퇴치 비율이 저절로 오른다. 캐논 3.2.2 목표("순수 퇴치 런은 레벨 약 +15% 빠름")를 맞추려면 밸런스 섹션은 **거리별 평균 x를 0.3~0.8 범위**에 두어야 한다. 백 위주 빌드는 x가 작은 적 무구(연타형)를 골라 해원 창을 지킬 수 있다. → 참조: 15-balance(신설 예정, 그전 임시 소유 02 §22·09-meta-economy)
- **설계 의도:** VS의 "강해진다 = 무조건 좋다"를 넋길에서는 "강해진다 = 한을 깨뜨린다"로 바꾼다. 이 마찰이 신빨에 선택의 무게를 준다.

## 5.5 결단 누적 확률

풀릴 기색 잡귀가 백 무구에 풀리기 전에 적 무구에 n번 맞으면, 결단타로 퇴치될 확률은 다음과 같다.
```
P(결단 퇴치) = 1 − (1 − 결단)^n
```

| 결단 \ n | 1 | 3 | 6 | 10 |
|---|---|---|---|---|
| 5% (기본) | 5% | 14.3% | 26.5% | 40.1% |
| 15% (명두) | 15% | 38.6% | 62.3% | 80.3% |
| 30% | 30% | 65.7% | 88.2% | 97.2% |

- 해원 빌드의 대응 3가지: ① 결단을 올리지 않는다. ② 백지술 Lv5 완성 효과(적 투사체가 풀릴 기색 적을 통과. 9장)를 집는다. ③ 풀릴 기색 무리를 적 무구 사거리 밖(방울 범위)으로 데려간다(동선).
- 명두(결단 +10%)는 **치명·퇴치 특화** 캐릭터라는 캐논 4.1 정체성과 맞는다.

# 6. 받는 피해 공식

## 6.1 처리 순서 (단발 피해 1건)

> **소유 (리뷰 대응 R-07):** 피격 파이프라인의 순서와 무적 시간은 **02 12.1과 `combat_core.json` `player`가 단일 정본**이다. 이 절은 스탯이 끼어드는 지점을 05 용어로 요약한다. 값이 다르면 02를 따른다. 07 2.4와 14의 "대신 맞기 → 회피" 순서는 02 순서(회피 → 대신 맞기)로 고치도록 요청한다.

```
on_player_hit(hit):                      # hit.type ∈ {CONTACT, PROJECTILE, HAZARD}, hit.tags
  1. if 무적 중: return                    # 투사체는 소모되지 않고 통과 (무적 출처 6.2)
  2. if hit.type == CONTACT and (undodgeable 태그 없음):
         if PRD_roll(접신 회피): "피함" 표시; 무적 0.20초; return
  3. if hit.type in (CONTACT, PROJECTILE) and 행렬 ≥ 1 and 대신맞기_쿨 == 0:
         맨 앞 영가 천도(넋 +1, 신명 +0.5%); 대신맞기_쿨 = 0.5초; 무적 0.20초; return
     elif hit.type in (CONTACT, PROJECTILE) and 신장 가호 보유 and 신장_쿨 == 0:   # 06 면 효과
         신장 대신 맞기; 신장_쿨 = 10초; 무적 0.20초; return
  4. if hit.type in (CONTACT, PROJECTILE) and 호신부 ≥ 1:
         호신부 −1; 가위눌림 해제; 무적 0.40초; return
  5. dmg = max(ceil(0.2 × hit.raw), hit.raw − 신복)       # HAZARD 틱은 신복의 50%만 적용
  6. 정기 −= dmg; 무적 0.40초 (HAZARD 틱은 무적을 주지 않는다)
  7. if 직전 정기 > 30% and 현재 정기 ≤ 30% and 호신 쿨 == 0: 몸주신 호신 (02 12.5)
  8. if 정기 ≤ 0: 명줄 처리(6.7) 또는 사망
```

| 순서 | 단계 | 이 위치인 이유 |
|---|---|---|
| 1 | 무적 | 연출 무적(빙의·명줄)이 다른 자원보다 먼저 막아야 자원 낭비가 없다 |
| 2 | 접신 회피 | 공짜 방어(소모 없음)를 먼저 굴린다. 회피에 성공하면 영가·호신부를 아낀다. **판정 대상은 적 본체 접촉(CONTACT)만**이다(02 12.1, `combat_core.player.dodge_contact_only`) |
| 3 | 대신 맞기 | 영가는 많고 천도 보상(넋 +1)도 있다. 캐논 3.2.3 "무당 피격 직전". 본체·탄 모두 막는다 |
| 4 | 호신부 | 희귀 소모품이라 영가가 없을 때의 마지막 보험이다 |
| 5 | 신복 | 실제로 정기가 깎일 때만 감면한다 |

## 6.3 접신 회피 PRD [NEW]

명목 확률 p에 대해, 직전 회피 이후 N번째 판정의 회피 확률을 `C(p) × N`으로 둔다. 회피하면 N = 1로 되돌린다. 장기 평균은 p와 같다.

| p (명목) | 10% | 15% | 20% | 25% | 30% | 35% | 40% | 45% | 50% |
|---|---|---|---|---|---|---|---|---|---|
| C(p) | 0.01475 | 0.03222 | 0.05570 | 0.08474 | 0.11895 | 0.15798 | 0.20155 | 0.24931 | 0.30210 |

- 표 사이 값은 선형 보간한다. 5% 미만은 일반 난수를 쓴다.
- **설계 의도:** 50% 회피를 일반 난수로 굴리면 6연속 피격 확률이 1.6%라 "운빨 사망"이 생긴다. PRD는 이 꼬리를 크게 줄인다. 상수는 Dota 2 계열에서 널리 쓰이는 PRD 상수표다(출처 19장).

## 6.6 신복 감면과 최소 피해

|---|---|---|---|---|---|---|
| 5 | 5 | 2 | 1 | 1 | 1 | 1 |
| 10 | 10 | 7 | 4 | 2 | 2 | 2 |
| 20 | 20 | 17 | 14 | 10 | 5 | 4 |
| 40 | 40 | 37 | 34 | 30 | 25 | 8 |

## 6.8 적 피해 기준치 (→ 07 3.2가 소유)

> **단일 출처 (리뷰 대응 R-03):** 적 피해는 `enemies.json` 종별 `contact_dmg × C(m)`, `C(m) = 1 + 0.06·m` 하나로 정한다(07 3.2). 웨이브 데이터의 `dmg_mult`는 곱하지 않는다(이중 적용 금지. 08 5.2 공식을 `base_dmg × C(m) × stage_dmg`로 고치도록 요청). 아래는 05의 파생 스탯(4.4 실효 감면)과 EHP 예시가 쓰는 **평균 일반 잡귀 기준값 `R(m) = 5 × C(m)`** 이다.

| 시각 | 00:00 | 05:00 | 10:00 | 15:00 | 20:00 |
|---|---|---|---|---|---|
| C(m) | 1.00 | 1.30 | 1.60 | 1.90 | 2.20 |
| **R(m) 평균 일반 잡귀 접촉** | **5** | 6.5 | **8** | 9.5 | **11** |

- 종별 값은 기본 4~8에 C(m)을 곱한다. 예: 달걀귀신(5) 5 → 8 → 11, 영산(8) 8 → 12.8 → 17.6.
- 적 탄, 정예, 장판 피해도 같은 식(종별 값 × C(m))이다. 중간보스·스테이지 보스는 등장 시각 기준 고정값이라 C(m)을 곱하지 않는다(07 3.2).
- 02 12.2 표(4/8/13)는 자기 공식 `4 × (1 + 0.045 × 분)`(10분 5.8, 20분 7.6)과도 맞지 않는다. 02 12.2·`combat_core.enemy_baseline`을 이 표(5/8/11)로 맞추도록 요청한다.

## 6.9 유효 체력(EHP) 근사 — 밸런스 확인용
```
EHP ≈ 정기 ÷ (받는 피해 / 원피해) ÷ (1 − 회피) + 행렬 영가 수 × 원피해
```
- 예 (10:00, R = 8): 정기 150, 신복 6, 원피해 8 → 받는 피해 max(⌈1.6⌉, 2) = 2(감면 75%), 회피 15%, 행렬 20
  → 150 ÷ 0.25 ÷ 0.85 + 20 × 8 ≈ 706 + 160 = **866** (원피해 8 기준 약 108회 접촉).
- 같은 빌드의 20:00(R = 11): 받는 피해 max(3, 5) = 5(감면 55%) → 150 ÷ 0.4545 ÷ 0.85 + 20 × 11 ≈ 388 + 220 = **608**(약 55회). 고정 감면이 후반에 약해지고 행렬이 그 몫을 메우는 구조가 숫자로 보인다(3.1.3 설계 의도).
- 대신 맞기 내부 쿨(0.5초) 때문에 실제 행렬 몫은 피격 빈도가 초당 2회를 넘으면 줄어든다. 회피는 본체 접촉에만 적용되므로 탄 비중이 큰 구간에서는 `(1 − 회피)` 항이 그만큼 약해진다.

- **설계 의도:** 2단계 추첨(범주 → 항목)을 쓰는 이유. VS처럼 모든 항목을 한 풀에서 뽑으면, 신령 권능(보이는 풀 4종 × 3레벨 × 최대 6신 = 72단계)이 늘어날수록 무구·패시브가 화면에서 밀려난다. 범주 가중치를 따로 두면 무구·패시브 몫을 고정할 수 있다. 권능 범주를 강신 등급과 무관한 고정값으로 둔 근거는 10.10 수급 예산이다.

## 10.4 항목 가중치

```
w(item) = base_w × luck_factor(tier) × owned_mult × focus_mult × evo_mult × deity_mult
```

| 항 | 값 | 설명 |
|---|---|---|
| `base_w` | 흔함 100 / 드묾 60 / 귀함 30 (항목별 지정 가능. 패시브는 9.2 표) | 무구·권능 미지정 시 흔함 100 → 참조: 04, 06 |
| `luck_factor` | 흔함 `1` / 드묾 `L^0.75` / 귀함 `L^1.5`, `L = clamp(점괘/100, 0.5, 3.0)` | 점괘가 희귀 항목만 끌어올린다 |
| `owned_mult` | 보유 중이고 레벨업 가능 ×1.3 | 빌드 수렴. 슬롯이 다 차면 보유 항목만 남으므로 사실상 무의미 |
| `focus_mult` [NEW] | **보유 무구만** `1 + 0.15 × (현재 Lv − 1)` (Lv1 ×1.0, Lv4 ×1.45, Lv7 ×1.9) | 키우던 무구가 더 자주 나와 Lv8로 수렴한다. 10.10 |
| `evo_mult` | 보유 무구의 **짝 패시브(미보유)** ×1.5 / 그 무구가 Lv8이면 ×2.5 / 보유 패시브의 짝 무구(미보유, 빈 슬롯) ×1.3 | 진화 경로 안내 |
| `deity_mult` | 가장 최근 빙의한 신령의 권능 ×1.5, 빙의 뒤 **일반 점지 3화면 동안** | 새 신령 체감. 06의 "빙의 후 60초" 창 대신 화면 수를 쓴다(아래) |

- **`deity_mult`를 화면 수로 정한 이유:** 시간 창(60초)은 레벨업이 빠른 퇴치 런에 더 많은 기회를, 느린 해원 런에 더 적은 기회를 준다. 화면 수 기준은 성향과 무관하게 같은 기회 수를 주고, 점지 난수 스트림(레벨 단위, 10.7)과 같은 단위라 시드 재현이 쉽다. `deities.json power_rules.jeomji.fresh_bias`(×1.5/60초)는 이 값(`stats.json jeomji.deity_recent_mult` ×1.5 / `deity_recent_screens` 3)으로 대체하도록 06에 요청한다.

## 10.7 추첨 의사코드

```
generate_jeomji(state, rng):
  N = 3 + (rng.jeomji.next() < P4(state) ? 1 : 0)
  pool = build_candidates(state)                                   # 10.2
  slots = []
  for g in [G2, G1, G6, G3] where g.applies(state) and len(slots) < 2:
      item = g.pick(pool, item_weights(state), rng)
      if item: slots.append(item); pool.remove(item)
  free_start = len(slots)
  while len(slots) < N and pool not empty:
      cat  = weighted_pick(categories_with_items(pool), category_weights(state), rng)   # 10.3
      item = weighted_pick(pool[cat], item_weights(state), rng)                         # 10.4
      slots.append(item); pool.remove(item)
  apply_G4(slots[free_start:], pool, rng)
  apply_G5(slots, free_start, pool, rng)          # 60% 판정도 rng.jeomji에서 굴린다
  while len(slots) < N: slots.append(next_filler(state))                                # 10.8
  return shuffle_display_order(slots, rng)        # 보장 칸이 항상 1번에 오지 않게 섞는다
```

- **난수 스트림 분리 [NEW]:** 점지는 전용 스트림 `rng_jeomji = Hash(run_seed, "jeomji", level, reroll_index)`를 쓴다(14 3.13.1 레지스트리의 키 파생 스트림, 캐논 v1.2 D-48). 결단·회피는 `rng_combat`이다. 전투 난수(결단, 회피)와 섞이지 않으므로 오늘의 굿판에서 같은 레벨·같은 상태면 같은 선택지가 나온다. 다시 묻기은 `reroll_index`를 1 올린다.
- 보장 카운터(G1의 "최근 3회", G2의 "3회마다")는 일반 점지 화면만 센다. 빙의 점지·다시 묻기 재추첨은 세지 않는다.

## 10.9 계산 예시 — 특정 패시브가 나올 확률

**상황:** 레벨 12, 점괘 100, 강신 등급 1(산신), 보장 G1·G2·G3 해당 없음.
- 무구: 신칼 Lv5, 방울 Lv4, 각궁 Lv2 (빈 슬롯 3) → **G6이 1칸을 보유 무구로 채운다.** 자유 추첨은 2칸.
- 패시브: 경면주사 Lv2, 미투리 Lv1 (빈 슬롯 4)
- 질문: 신칼의 짝 **백지술**이 이번 화면에 나올 확률은?

**패시브 범주 안 가중치:**
- 보유: 경면주사 60 × 1.3 = 78, 미투리 100 × 1.3 = 130
- 미보유 짝 보정: 백지술 100 × 1.5 = 150 (신칼 짝), 초혼 적삼 100 × 1.5 = 150 (방울 짝)
- 나머지 미보유: 신장대 30, 무복·정화수·명주실·오방끈·촛대·엽전·산통 각 100 (=700), 궁채 60, 바릿대 60, 제웅 50, 위패 60
- 합계 = 78 + 130 + 150 + 150 + 30 + 700 + 60 + 60 + 50 + 60 = **1,468**
- P(백지술 | 패시브 범주) = 150 / 1,468 = **10.2%**

**범주 가중치:** 무구 40, 패시브 30, 권능 20 → P(패시브) = 30/90 = 33.3%

**자유 칸 1칸 확률** ≈ 0.333 × 0.102 = 3.4% → **자유 칸 2칸** ≈ 1 − (1 − 0.034)² ≈ **6.7%** (중복 제거 효과로 실제는 약간 높다)

- 신칼이 Lv8이 되면 `evo_mult` ×2.5 → 백지술 가중 250, 범주 합 1,568 → 패시브 범주 안 15.9% → 자유 2칸 화면당 약 10.3%. 여기에 **G2(3회마다 1회 보장)**가 붙어 늦어도 3번째 점지에는 나온다. 이때 G6은 신칼(Lv8, 후보 아님)을 빼고 방울·각궁 중에서 뽑는다.

# 12. 점괘가 관여하는 다른 확률

## 12.1 상자 등급 (길흉 상자 `box_gilhyung`, 넋함 `box_neokham`)

> **정본 = 02 18.1 · `combat_core.json chest` (캐논 v1.2 C-18).** 등급 ID·이름·확률식·보상 수·등급 상승은 02가 소유한다. 05는 점괘가 그 식에 들어간다는 것만 적는다. 이전 판의 05 자체 식(`P5 = min(0.30, 0.04 × L²)`, `P3 = min(0.55, 0.20 × L^1.5)`)과 등급 이름 '평·길·대길'은 폐기했다.

```
J = clamp(점괘 / 100, 0.5, 3.0)       (엽전 꾸러미 완성 시 점괘 +25로 계산)
등급 = jg_sogil 소길(보상 1) / jg_junggil 중길(보상 3) / jg_daegil 대길(보상 5)
p(대길) = min(cap, base × J), p(중길) = min(cap, base × J), p(소길) = 나머지
  길흉 상자: 대길 base 0.03 · cap 0.25 / 중길 base 0.12 · cap 0.40
  넋함:      대길 base 0.08 · cap 0.30 / 중길 base 0.22 · cap 0.45
판정 후 등급 상승: 대감 위엄 빙의(06 값, 현행 25%), 심방 +10%p (각각 독립 판정, 1단계씩)
```

| 점괘 | 길흉 상자 소/중/대 | 넋함 소/중/대 |
|---|---|---|
| 100 | 85% / 12% / 3% | 70% / 22% / 8% |
| 150 | 77.5% / 18% / 4.5% | 55% / 33% / 12% |

- 고정 규칙(02 18.1): 중간보스 상자는 최소 중길, 원귀 퇴치 상자는 등급 +1 확정. 05 소유분은 제웅 완성 시 원귀 상자 추가 +1단계(판정 뒤 적용, 대길 상한)뿐이다.
- **내용물 우선순위 (정본 02 18.2·`combat_core.chest.contents`, 아래는 05 이전 판 요약):** ① 결합 가능 → 결합 ② 진화 가능 → 진화 ③ 보유 무구·패시브·권능 레벨업(10.4 가중치에서 미보유 제외) ④ 엽전. 진화·결합은 상자당 최대 1회.

## 12.2 길흉 연출 판정 (표시 전용)

- 길흉 상자 = **엽전 홀짝 점복**: 엽전 7~9개를 던져 홀수면 '길'. 소길(보상 1) = 1투 홀 "소길(小吉)", 중길(보상 3) = 3투 연속 홀 "중길(中吉)", 대길(보상 5) = 5투 연속 홀이고 마지막 투는 7개 전부 앞면 "대길(大吉)". 앞면 수는 늘 홀이다(짝은 나오지 않는다: 흉 없음). 연출 길이는 소길·중길 약 2.5초, 대길 약 4.5초. 연출 세부는 02 18.3이 정본이다.
- 넋함 = **산통점**: 산가지 1~3개가 튀어나옴(소길·중길·대길 = 보상 1/3/5).
- 결과는 12.1에서 이미 정해진다. 연출은 그 결과를 보여 줄 뿐이고 플레이어 입력은 없다(P4: 판정 없음).
- '흉(凶)' 표기는 쓰지 않는다. 가장 낮은 결과도 '소길'이다(보상을 벌처럼 느끼게 하지 않는다. 02 18.1, 캐논 v1.2 D-07: 이름은 '길흉 상자' 유지, 결과에 흉이 없다는 점은 도감에 적는다).

## 12.3 점괘가 관여하지 않는 것 (명시)
결단타, 접신 회피, 픽업 드롭률, 원혼 구슬 크기, 사연 조각 판정(넋함은 사연 조각 확정. 캐논 4.10). 점괘의 의미를 "선택의 질"로 좁혀 둔다.

## 14.3 빌드 기울기 바 (`ui_build_tilt`) [NEW]

tilt_score = Σ(적 기울기 항목 레벨 비중) − Σ(백 기울기 항목 레벨 비중)
  항목 레벨 비중 = 보유 레벨 / 최대 레벨 (무구 8, 패시브 5, 권능 3)
  색 무구는 ×2 가중 (무구 색이 막타 색을 가장 크게 결정하므로)
표시 = −1(풀기) … 0 … +1(깎기) 로 정규화한 바늘
```
- 위치: 스탯 패널 상단, 점지 화면 우상단(작게). 양끝 라벨 "깎기 ← → 풀기". 숫자 없음.
- 이번 런의 실제 해원 비율(정산 지표)을 바늘 아래 얇은 선으로 함께 보여 줘서, 빌드 성향과 실제 결과를 비교하게 한다.

# 16. 계산 예시 모음

## 16.1 적 무구 피해 + 한 파열 판정
- 상황: 10:00, 만신, 신빨 140%(경면주사 Lv5 +40%), 범 위엄(적 근접 +40% × M2 1.15 = +46%) 보유.
- 월도 Lv6 `D0 = 30`(가정), 대상 처녀귀신 최대 한 60(가정), 현재 한 60, 살기 30 → 실효 최대 한 60 × 1.06 = 63.6.
- 피해 = 30 × 1.40 × (1 + 0.46) × 1.0 × 1.0 = **61.3**
- x = 61.3 / 63.6 = 0.96 → 만피에서 1타 후 한 2.3 (3.6%) → **풀릴 기색 진입**(0.65 ≤ x < 1 구간).
- 신빨이 Lv5 대신 Lv5 + 권능 +10%로 150%였다면 피해 65.7 > 63.6 → **한 파열(퇴치)**. 신빨 10%p 차이가 동사를 바꾼다(신빨 딜레마).

## 16.2 백 무구 해원
- 같은 처녀귀신(한 2.3, 풀릴 기색)에 방울 Lv4 `D0 = 6`(가정), 단골(백 +25%), 풀이 ×3.0.
- 피해 = 6 × 1.40 × 1.25 × 3.0 = **31.5** ≥ 2.3 → **해원**(원혼 구슬 60%, 넋 +1, 영가 +1).

## 16.3 받는 피해
- 박수(정기 120 + 명주실 Lv3 +30% → (100) × (1 + 0.2 + 0.3) = 150), 무복 Lv3(신복 3), 행렬 0, 호신부 0, 회피 0.
- 정예 강타 원피해 25(07 종별 값 × C(m) 가정) → max(25 − 3, ⌈5⌉) = **22** → 정기 150 → 128, 무적 0.40초.
- 같은 무당이 10:00 평균 잡귀 접촉(R = 8)을 맞으면 max(8 − 3, 2) = 5. 이 접촉은 본체 접촉이라 회피 판정 대상이지만 탄이면 회피를 굴리지 않는다(6.1).

## 16.4 장단과 발동
- 신칼 Lv8 기본 쿨 1.2초(`weapons.json`), 궁채 Lv5(−30%) + 장군 위엄(−10%) + 신명 오름 R3(−15%p) = 1 − 0.55 = **0.45** (하한 25% 위).
- `cd` = 1.2 × 0.45 = 0.54초. 자진모리 구 1/2박 그리드(0.25초) → 2.16그리드 → 간격 2·2·2·2·2·3·… (평균 0.54초). 캐논 v1.2 1/3박 그리드(0.167초) → 3.24그리드 → 3·3·3·4·… (평균 0.54초). **그리드가 바뀌어도 평균은 같다.**
- 신명 오름이 끝나면 장단 0.60 → `cd` 0.72초 → 구 1/2박 그리드 2.88칸 → 3·3·3·3·3·3·3·2…, v1.2 1/3박 그리드 4.32칸 → 4·4·5·4·…. 오름 전후 발사 속도 차이는 0.72 / 0.54 = **+33%**다.
- 박 머리 무구(장구·합장단)는 그리드 g = 1박(자진모리 0.5초)이라 같은 계산을 1박 단위로 한다.

## 16.5 고리 면적
- 미투리 Lv5(도무 140% = 5.6유닛/s) + 미투리 완성(길베 4.5초), 단골(스냅 1.8).
- P = 5.6 × 4.5 + 1.8 = 27.0 → A_max = 729 / 12.566 = **58.0타일²**, A_실전 ≈ 41 → 만다라(60)는 신명 오름(길베 ×2 = 9.0초 → P 52.2 → A_max 217)에서 확실해진다. 오방끈 완성(기준 50)이 있으면 평상시 완벽한 원에 가깝게 그려서 노려볼 만하다.

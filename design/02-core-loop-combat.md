### 0.2 이 문서의 범위

포함: 조작, 이동 물리, 카메라, 자동공격 규칙, 피해 공식, **한(恨) 상태기계(풀릴 기색·매듭 잠금·퇴치/해원)**, 영가 행렬, 길베·길닦음 판정 알고리즘, 살기(전투 측), 신명·장단·박 양자화, 적대법/순종법 분기와 상태이상, 피격·무적·방어 파이프라인, 넉백, 히트스톱·셰이크·피드백 티어, 어둑시니 판정, 시련의 전투 통합, 점지(레벨업) 흐름과 경험치 곡선, 길흉 상자·넋함 점복 연출, 런 종료 조건, 30초·5분·20분 경험 곡선, 텔레메트리.

제외(다른 섹션 소관): 무당별 수치(→ 03), 무구별 레벨 1~8 수치·진화 레시피·`ritual_ref`(→ 04), 스탯 공식·점지 카드 생성·다시 묻기(재점)/물림/금기(→ 05), 신령 권능·화신 패턴·위엄/가호 게이지(→ 06), 적 종별 수치·AI·적 쪽 상태이상 저항(→ 07), 분 단위 스폰 테이블·정예 예약·이벤트 시각(→ 08), 재화 획득량·환산·메타(→ 09), 서사·종장(→ 10), HUD 레이아웃·온보딩 힌트(→ 11), 사운드 믹스(→ 12), 아트(→ 13), 엔진·세이브·성능 구현(→ 14).

### 0.3 다섯 줄 요약

1. 입력은 **이동 하나**다. 대시와 액티브 버튼은 없다. 그 대신 **길닦음(이동으로 그리는 고리)이 유일한 액티브 스킬**이고, 회피는 영가 대신 맞기·접신 회피·[NEW] 몸주신 호신으로 자동 처리한다.
2. 모든 적은 `hs_normal → hs_giseak → (해원 | 퇴치 | 맺힘 복귀)` 상태기계를 돈다. 마지막 피해의 **색(적/백)**과 **상태**가 결과를 정한다. 같은 틱에서는 **백이 먼저** 처리된다.
3. 무구는 **장단 그리드 틱에서만** 발동하되, **잔여 이월**(캐논 v1.1 3.2.8, 구현 04 2.4.2)로 평균 주기는 쿨다운 그대로다. 개별 간격은 그리드 칸 수로 이산화되어 '가락'으로 들리고, 장단 스탯 1%도 버려지지 않는다.
4. 히트스톱은 **드문 사건에만** 쓴다(길닦음·정예 결과·보스). 1초에 수백 번 일어나는 일반 타격은 개체 단위 2프레임 정지와 색 틴트로만 표현한다. 전역 히트스톱에는 예산 상한을 둔다.
5. 레벨 곡선은 `req(L) = round(5 + 6(L−1) + 0.13(L−1)²)`다(02 소유, 확정). 혼합 런 기준 20:00에 약 **Lv49**(퇴치형 56, 해원형 44, 17.2)이다. 이 값이 전 섹션 공용 가정이다.

## 2. 루프 계층 구조

```
[1.5초]  미세 리듬   : 무구 1~3회 발동(박 그리드) → 한 깎임 → 풀릴 기색 점등
[30초]   마이크로 루프: 몰이 → 깎기(적) → 풀기(백) → 행렬 → 고리(길닦음) → 점지     (21.1)
[3~4분]  거리 루프   : 장단 1구간 + 시련 1회(빙의) + 정예/이벤트 1~2                  (21.2)
[20분]   굿판(런)    : 열두거리 6구간 + 시련 4(모신 4신) + 중간보스 + 합일 + 뒷전 + 보스 2형 + 명부 정산  (21.3)
[다회]   메타        : 넋→공덕, 엽전→복전, 사연 조각, 명두 계승              → 참조: 09
```

각 층의 **결정**과 **보상**을 겹치지 않게 나눈다:

| 층 | 플레이어 결정 | 즉시 보상 | 지연 보상 |
|---|---|---|---|
| 1.5초 | 어디로 걷나(몰이·회피) | 타격음·한 깎임·풀릴 기색 얼굴 | — |
| 30초 | 이 무리를 깰까 풀까 / 고리를 지금 닫을까 | 해원 빛·영가 합류·길닦음 폭발 | 점지 |
| 3~4분 | 시련에서 어느 신령, 어느 면(위엄/가호 두 게이지 중 먼저 찬 쪽) | 빙의 변신·악기 합류 | 권능 풀 개방 |
| 20분 | 붉음/흰 비율(살기 관리), 살을 거둘까 둘까(9.2) | 등불·벽사 오름·원귀 회귀 | 보스 형태·정산 |
| 메타 | 무엇을 해금할까 | 넋기록 | 동행령·무구 선택지 |

### 3.4 향함(Facing)

- `facing` = 마지막으로 0이 아니었던 이동 벡터(연속 각도). 정지해도 유지한다.
- 스프라이트 방향은 4방향(남·북·동·서, 캐논 6.2)이다. 45° 경계에 **±10° 히스테리시스**를 둔다(대각선 이동 시 깜빡임 방지).
- `facing`을 쓰는 곳: 방향형 무구(삼지창·장창·편곤·부채·길베 무구), 어둑시니 시야 원뿔(15장), 호작도(등 뒤 = `−facing`), 카메라 룩어헤드(4장).

### 3.5 대시를 넣지 않는다 — 그 대신 무엇이 그 일을 하나

대시가 장르에서 하는 일은 ① 긴급 회피 ② 포위 탈출 ③ 숙련 표현 세 가지다. 넋길은 각 기능을 **입력 없이** 다른 장치에 나눠 맡긴다.

| 대시의 기능 | 넋길의 대체 장치 | 작동 방식 | 수치 |
|---|---|---|---|
| ① 긴급 회피 | **영가 대신 맞기** (캐논 3.2.3) | 피격 직전 맨 앞 영가가 대신 맞고 천도 | 내부 쿨 0.5초, 12장 |
| ① 긴급 회피 | **접신 회피** `stat_jeopsin_hoepi` | 접촉 피해 확률 무효 | 기본 0%, 상한 50% |

| ③ 숙련 표현 | **길닦음 고리 · 동선** | 고리의 크기·타이밍·위치 | 8장 |

**(왜)** 대시는 두 번째 입력이다. 대시를 넣으면 "걷기만 하면 굴러간다"는 바닥이 무너지고, 고리 그리기와 대시가 같은 손가락을 두고 경쟁한다(대시 중 길베 처리, 무적 중 고리 판정 같은 예외가 폭증한다). 캐논 P5의 하지 않을 것 목록과 같은 방향이다.

### 3.6 '액티브'의 정의 — 길닦음이 유일한 액티브 스킬

| 비교 | 일반 액티브 스킬 | 넋길 길닦음 |
|---|---|---|
| 발동 | 버튼 | 자기 길베에 1.5u 이내로 다시 들어가기 |
| 쿨다운 | 수 초~수십 초 | 1.0초(사실상 '그릴 수 있는 만큼') |
| 자원 | 마나·게이지 | 길베 지속 4초(`stat_gilbe`) = 시간 창 |
| 효과 범위 | 고정 | **그린 면적**이 범위 |
| 숙련 축 | 타이밍 | 타이밍 + 위치 + 크기 + 행렬 소모 판단 |

다른 '자동 액티브'(신명 오름, 신령 합일, 작두 강림)는 모두 **조건 충족 시 자동 발동**이다.

### 4.2 추종 리그 (매 프레임, 이동·물리 해석 **이후** 갱신)

```
1) 데드존   : 원형 반경 0.25u(8px). 초점 focus를 데드존 밖으로 넘친 거리만큼만 이동
2) 룩어헤드 : lead_goal = facing × 1.0u × (현재속도 / 기본속도, 최대 1.5)
              lead = lead.lerp(lead_goal, 1 − exp(−4.0·dt))      # 약 0.25초에 수렴
3) 평활     : cam = cam.lerp(focus + lead, 1 − exp(−10·dt))      # 프레임레이트 독립
4) 한계     : |cam − player| ≤ 1.6u (넘으면 즉시 클램프)
5) 셰이크   : cam_final = cam + shake_offset (14.3, 가산, 정수 픽셀 반올림)
6) 픽셀 스냅: 렌더 오프셋을 1/업스케일 픽셀 단위로 스냅(서브픽셀 스크롤, 아래 4.4)
```

| 파라미터 | 값 | JSON |
|---|---|---|
| 데드존 반경 | 0.25u | `camera.deadzone_u` |
| 룩어헤드 거리 | 1.0u (속도 비례, 최대 1.5u) | `camera.lookahead_u`, `camera.lookahead_max_u` |
| 룩어헤드 평활 | rate 4.0/s | `camera.lookahead_rate` |
| 추종 평활 | rate 10.0/s | `camera.follow_rate` |
| 최대 이탈 | 1.6u | `camera.max_offset_u` |

**(왜)**
- 룩어헤드를 1.0u로 작게 둔다. 뱀서라이크의 위협은 360°에서 온다. 진행 방향을 크게 내다보면 등 뒤가 잘린다. 어둑시니 공략이 '등 돌려 걷기'이므로 등 뒤가 보여야 한다.
- 길베는 4초 × 4u/s = 16u다. 고리 지름은 약 5u이고, 이 정도는 화면 세로 11.25u 안에 들어온다. **기본 스탯에서 내가 그린 고리 전체가 항상 화면에 보인다.** 도무·길베 스탯을 올려 고리가 화면보다 커지면 화면 밖 길베의 끝을 10장 UI의 '길베 꼬리 화살표'로 표시한다(→ 참조: 11).
- 데드존이 작으면 미세한 좌우 흔들림에도 카메라가 따라오지 않아 멀미가 줄어든다.

```
  × M_state                             # 백 & 대상 풀릴 기색 → stat_puri (기본 3.0, 상한 6.0), 그 외 1.0
  × (1 + Σ 조건부 보너스%)               # 벽사록 종별 +3/6/10%, 범 위엄 근접 +40%, 공포 대상 +20% 등 (같은 버킷은 가산)
  × M_crit                              # 적 무구만. 결단 성공 시: 일반·정예 이상 ×2.0 [NEW 값], 풀릴 기색 일반 잡귀 → 결단타(6.2)
  × M_resist                            # 대상 종별 저항/약점 → 07 (기본 1.0, 범위 0.5~1.5)
D_final = max(1, D)                     # 최소 1 (매듭 잠금 클램프는 그 다음 6.2에서 적용)
```

> 캐논 3.2.2를 구현 수준으로 푼다. 규칙(무엇이 무엇을 일으키는가)은 캐논 그대로이고, 이 장에서는 **순서·타이밍·예외**를 확정한다.

### 6.1 상태 정의

|---|---|---|---|---|---|

`r = 현재 한 / 최대 한`. 경계값: `r ≤ 0.35`면 기색(같음 포함), `r > 0.35`면 맺힘.

### 6.2 피해 해석 의사코드 (단일 타격)

```python
def resolve_hit(target, hit):            # hit.color ∈ {RED, WHITE}, hit.dmg = D_final (5.3)
    if target.state in (HAEWON_PENDING, RESOLVED): return
    if target.kind == AVATAR:     return trial_contribution(target, hit) # 16장: 한·HP 없음, 06 trial_gauge
    if target.kind == EODUKSSINI: return eodukssini_hit(target, hit)    # 15장
    if target.kind == BOSS:       return boss_phase_hit(target, hit)    # → 07 (보스 2형)

    r_before = target.han / target.han_max
    crit = (hit.color == RED) and rng.combat() < stat_gyeoldan

    # ── 적(赤) ─────────────────────────────────────────────
    if hit.color == RED:
        if target.state == GISEAK and target.grade == GENERAL:
            if crit:                                   # (b) 결단타
                return toechi(target, cause="gyeoldanta")
            target.han = max(target.han - hit.dmg, 1)  # 매듭 잠금: 1 미만 불가
            feedback_knot_block(target)                # 6.6 '매듭 막힘' 반짝임
            return
        dmg = hit.dmg * (CRIT_MULT if crit else 1)
        target.han -= dmg
        if target.han <= 0:
            if r_before > 0.35 and target.grade == GENERAL:
                return toechi(target, cause="han_pa")  # (a) 한 파열
            if target.grade >= ELITE:
                return toechi(target, cause="elite")   # (c) 정예 이상
        if target.state == NORMAL and target.han / target.han_max <= 0.35:
            enter_giseak(target)
        return

    # ── 백(白) ─────────────────────────────────────────────
    mult = stat_puri if target.state == GISEAK else 1.0
    target.han -= hit.dmg * mult
    if target.han <= 0:
        return haewon(target, cause=hit.source)        # 맺힘에서 단번에 0이 돼도 해원
    if target.state == NORMAL and target.han / target.han_max <= 0.35:
        enter_giseak(target)
```

| 해석 세부 | 규칙 | (왜) |
|---|---|---|
| 정예 이상 기색 + 적 무구 | 매듭 잠금 없음. 한 0 → 퇴치(c) | 캐논 |
| 일반 잡귀 맺힘 + 적 1타로 0 이하 | 한 파열 퇴치(a). 결단 ×2.0이 한 파열을 돕는다 | 캐논. 고신빨 빌드가 자연스럽게 퇴치로 가는 경로 |
| 일반 잡귀 맺힘 + 적 1타로 0 < r ≤ 0.35 | 기색 진입. 한은 깎인 그대로(클램프 없음) | 깊게 깎인 기색은 백 1타로 풀린다 |
| 백 1타로 맺힘 → 0 이하 | **해원**(기색을 건너뜀) | 캐논 "백 무구가 한을 0으로". 백 기본 피해가 낮아 드물다 |
| 지속 피해(화상 등) | 원천의 색을 그대로 가진다(화상 = 적). 틱마다 `resolve_hit` 호출, 결단 판정 없음 | 색이 섞이지 않는다(P1: 2색 고정) |
| 양면 무구 `union_*` | 타격 시점 대상 상태로 색을 정한다. 기색이면 백, 그 외는 적 | 캐논 3.2.12 |
| 매듭 잠금 상태에서 한 = 1 | 적 무구는 계속 맞히지만 피해 0. 숫자 없이 '매듭 막힘' 반짝임만 | 학습 신호: "빨간 걸로는 안 끊어진다" |

### 6.3 같은 틱 안의 해석 순서 (결정성)

### 6.7 예시 시나리오

**예시 A — 신칼로 깎고 방울로 푼다 (00:45, 만신)**
1. 달걀귀신(최대 한 12, 07 5.1)이 신칼 1타에 10 피해를 받는다. 한 2, r = 0.17, 기색에 진입한다(얼굴 교체).
2. 돌아오는 신칼 2타가 10 피해를 준다. 매듭 잠금으로 한은 1에서 멈추고 매듭 막힘이 반짝인다(느슨한 매듭).
3. 무당이 그쪽으로 걸어가 방울 오라(반경 2.5u)에 넣는다. 방울 틱 1 × 3.0 = 3 ≥ 1이므로 **해원**. 원혼 구슬 0.6, 넋, 영가 합류.

**예시 B — 한 파열 (14:00, 고신빨 사인참사검)**
- 수비(최대 한 6 × T(14) ≈ 35, r = 1.0)가 검기 1타에 55 피해를 받는다. 맺힘에서 단번에 0 이하가 되므로 **한 파열 퇴치**. 살 알갱이가 남고 살기 +0.02.

**예시 C — 같은 틱 경합 (09:00)**
- 기색 상태 객귀(한 3)에게 같은 틱에 각궁(적)과 지전(백)이 동시에 맞는다. 6.3 순서대로 지전(백)을 먼저 해석한다. 2 × 3.0 = 6 ≥ 3이므로 **해원**. 각궁 타격은 무시되고 결단 판정도 하지 않는다.

**예시 D — 결단타 (11:20, 명두 결단 25%)**
- 기색 상태 처녀귀신 뒤에 맺힘 상태 몽달귀신이 있다. 각궁은 처녀귀신을 조준하지 않고(5.2) 몽달귀신을 쏜다. 화살이 처녀귀신을 **관통 소모 없이** 지나가며 판정하고, 결단에 성공한다(25%). **결단타 퇴치**, 화살은 그대로 날아가 몽달귀신을 맞힌다.

### 7.4 대신 맞기

```
on_player_would_be_hit(hit):
    if hit.type in (CONTACT, PROJECTILE) and substitution_cd <= 0:   # 장판 틱 제외
        y = 행렬에서 동행령이 아닌 가장 앞(i 최소) 영가
        if y exists:
            y → 천도(대신 맞기)
            substitution_cd = 0.5초
            player_iframe   = max(player_iframe, 0.20초)
            return BLOCKED              # 무당 피해 0
    → 12장 피격 파이프라인 계속
```

| 항목 | 값 | (왜) |
|---|---|---|
| 내부 쿨 | 0.5초 (캐논) | — |
| 대신 맞은 뒤 무적 | 0.20초 [NEW 값] | 쿨(0.5초)보다 짧다. 무리에 계속 닿아 있으면 대신 맞기와 무당 피격이 번갈아 일어나 받는 피해가 줄어든다. 행렬은 든든한 감쇠 방패이지 무적 방패가 아니다 |
| 장판 지속 피해(역병·검은 물 등) | 대신 맞기 대상 아님 | 장판 틱마다 영가가 사라지면 행렬이 녹는다 |
| 보스 강공격 | 캐논대로 영가 1기가 전부 흡수 | [CANON-REQUEST R2: '중타(重打)' 플래그 — 피해가 최대 정기의 25% 이상이면 영가 ceil(피해/25)기(최대 5기) 소모]. 승인 전 OFF (`yeongga.heavy_hit_rule_enabled = false`) |

**연속 접촉 시 기대 피해 예** (대신 맞기 쿨 0.5초, 대신 맞은 뒤 무적 0.2초, 피격 후 무적 0.4초):
- `t=0` 대신 맞기 → `t=0.2` 무당 피격, 무적이 0.6초까지 → `t=0.6` 대신 맞기(쿨 경과) → `t=0.8` 피격 → … 반복.
- 피격 간격이 0.4초(행렬 없음)에서 0.6초로 늘어 **받는 피해 −33%**. 영가는 0.6초에 1기씩 소모되므로 24기면 14.4초를 버틴다.

### 8.3 면적 판정 (격자 래스터 + 플러드필)

```python
def run_ring(loop, m):
    bbox = loop의 경계 상자를 1u 격자로 확장 (+1칸 여백)
    grid = bbox 크기의 2D 배열 (0)
    for seg in loop의 연속 선분 + (head → m) 닫는 선분:
        supercover_DDA(seg) → 지나는 모든 셀 = WALL
    flood_fill(시작 = bbox 테두리 모든 셀, 통과 = 비WALL) → OUTSIDE
    interior = OUTSIDE도 WALL도 아닌 셀
    area = len(interior)                   # 면적(타일²)은 내부만
    if area < 9: return                    # 실패: 쿨·길베 소모 없음, 피드백 없음
    zone = interior ∪ WALL                 # 효과 범위는 경계 포함
    # v0.10 빈 고리 가드: 의도 없이 돈 카이팅 고리는 비용 0
    n_giseak  = zone 안 기색 적 수 (화신 제외)
    n_enemies = zone 안 적 수 (화신 제외)
    if n_giseak < 1 and n_enemies < 3:

        return                             # 효과·길베 소모·쿨다운 모두 생략
```

### 10.2 무구 발동 양자화 (v0.11: 잔여 이월(위상 이월) `phase_carry` — 캐논 v1.2 D-21, 정본 05 3.2.2a)

> 이전 판의 '올림(ceil)' 규칙, 실효 주기 표, 설계 함의 1~3, `ui_garak_dangye`는 **삭제**했다(리뷰). 올림 규칙에서는 쿨 1.0초 무구가 중중모리에서 1.26초(DPS −21%)가 되고, 궁채 Lv1(−6%) 같은 점지가 여러 거리에서 실효 0인 '죽은 픽'이 됐다. 같은 문단의 "장단이 빨라지면 실효 주기가 짧아진다"도 자기 표와 맞지 않았다.

**규칙(캐논 v1.2 3.2.8, D-21):** 무구는 그리드 틱에서만 발동하되, 이상 발동 시각(위상)을 이월해 그리드를 기다리며 늦어진 시간을 다음 발동에서 돌려받는다(**잔여 이월(위상 이월)**). 단순 올림은 금지한다. **정본 알고리즘은 05 3.2.2a `phase_carry`**이고(`combat_core.json` `jangdan.quantize_rule = "phase_carry"`), 구현은 그 의사코드 하나로 한다. 아래는 02가 쓰는 요약이다(평균 주기 = P_eff, 밀린 위상이 1그리드를 넘으면 넘친 이월은 버림).

```
P_eff = max(무구 min_period(04 2.6), C_base × max(F, stat_jangdan), g)   # F = 0.40, 신명 오름 중 0.25
on_grid_tick(t):                       # 무구 그리드(10.1)마다, 게임 시간 기준 (05 3.2.2a 요약)
    if t + ε >= w.ideal_t and t >= w.last_fire_t + g:   # 최소 간격 1그리드
        fire(w)                        # 이 틱에 발동(박에 맞음)
        w.last_fire_t = t
        w.ideal_t += w.P_eff           # 실제 발동 시각이 아니라 이상 시각에 더한다(위상 이월)
        if t - w.ideal_t > g:          # 밀린 위상이 1그리드 초과(정지·경직·템포 전환)
            w.ideal_t = t + w.P_eff    #   넘친 이월은 버린다(몰아치기 방지)
on_cd_change(): 05 3.2.2a (ideal_t를 비례 재계산). on_bpm_change(): 다음 틱부터 새 g
```

→ 해원 1마리는 XP 0.4e를 내주고 **방어 1회 + 화력 + 메타 재화**를 산다. 퇴치 1마리는 XP와 함께 **벽사 기세의 재료**를 바닥에 남긴다. 두 경로 모두 '줍는(데려가는/거두는) 이동'이 보상을 키운다.

**결정 2: 고리를 지금 닫을까, 행렬을 더 익힐까 (v0.10 개정)**

| 지금 닫기 (익은 넋 n기, 덜 익은 넋 k기, 기색 m마리) | 더 들고 다니기 |
|---|---|
| 기색 m 일괄 해원, 신명 +min(2m, 15)% | 익은 넋 n기의 오라 ×2 유지 + 대신 맞기 방패 |
| 익은 넋(남은 수명 ≤ 10초) n기 천도: 넋 `cheondo_in_ring`(×2) × n, 정기 +n% (10초 누적 상한 +10%) | 익은 넋은 수명이 다하면 고리 보너스 없이 `cheondo` × 1로 천도 |
| 덜 익은 넋 k기: 수명 +5초 + 오라 1박 폭발(틱 ×4). **행렬은 남는다** | 기색 무리가 더 모이고 행렬이 길어진다 |

→ 이전 판의 "지금 닫으면 행렬이 비어 무방비"는 사라졌다(캐논 v1.1). 이제 결정은 **"익은 넋을 언제 보낼까"**다. 너무 일찍 닫으면 보낼 넋이 적고(덜 익은 넋은 북돋움만 받음), 너무 늦으면 익은 넋이 수명으로 흩어져 고리 넋 ×2를 놓친다. 익은 넋 구간은 기본 10초(머문 20~30초)라 30초 마이크로 루프 안에 한 번 정도 '좋은 순간'이 온다. 위기(정기 낮음)에는 고리가 회복 수단이지만 **10초 누적 상한 +10%** 때문에 고리를 연타해도 회복은 10초당 10%를 넘지 않는다.

## 13. 넉백

### 13.1 적에게 주는 넉백

```
변위 d = KB_무구 × mass_factor × state_factor × dr_factor
적용   : 0.12초 동안 ease-out quad로 변위, 그 동안 AI 이동 정지, 이후 0.05초 회복
방향   : 근접·오라·파동 = 무당 → 적 방향 / 투사체 = 투사체 진행 방향 / 부채꼴 = 부채 중심축
```

| 계수 | 값 |
|---|---|
| KB 등급(무구별, → 04) | 약 0.3u / 중 0.8u / 강 1.5u |
| mass_factor | 일반 잡귀 1.0, 정예 0.25, 중간보스 0.1, 보스·화신 0 |
| state_factor | **풀릴 기색 0.5** |
| dr_factor | 직전 넉백 후 0.30초 안에 다시 넉백되면 ×0.5 |
| 상한 | 한 적이 0.5초 동안 받는 총 변위 3.0u |
| 지형 | 장애물에 닿으면 멈춤(벽 충돌 피해 없음) |

**(왜) 기색 0.5:** 붉은 무구(편곤 강타 등)가 기색 잡귀를 화면 밖으로 날려 보내면, 풀어 주려던 대상이 사라진다. 기색 개체는 '무거워져' 제자리에 머문다. 사람 얼굴로 돌아와 힘이 빠진 상태라는 해석과도 맞는다.

## 15. 어둑시니 — 입력 없는 역발상 (캐논 3.2.9 구현)

### 15.1 크기 모델

```
size ∈ [0.30, 3.00] (스폰 시 1.00)                  # 1.00 = 기본 스프라이트 96px
매 고정 스텝:
  in_cone  = angle(facing, 어둑시니 − 무당) ≤ 45°  and  거리 ≤ 12u     # 90° 원뿔
  gazer    = 바라보는 영가가 배정되어 있는가 (15.2)
  rate = 0
  if in_cone and not gazer: rate += +0.04/초                # 관심을 먹고 자람
  if not in_cone:           rate += −0.08/초                # 등 돌려 걷기
  if gazer:                 rate += −0.12/초                # 영가가 대신 바라봄
  if 등불 반경 안 and rate > 0: rate × 0.5                  # 캐논: 성장 −50%
  size += rate × dt
  on 적 무구 피해: size += 0.03 (초당 누적 상한 +0.15/초)   [NEW 상한, TUNE]
  on 백 무구 피해: size −= 0.02/타 (명두·광명 태그 포함)
  if size ≤ 0.30: 소멸 → 정적 드롭(15.3) → 해원 처리(6.5)
```

| 크기 영향 | 공식 |
|---|---|
| 몸통 반경·스프라이트 | × size (픽셀아트는 1.0/1.5/2.0/2.5/3.0 5단 스프라이트 교체 + 그 사이 정수 배율 근사) |
| 접촉 피해 | 정예 기준 × size |
| 이동속도 | 기본 2.4u/s(무당의 60%) × (1 / sqrt(size)) — 커질수록 느리지만 넓다 |
| 시야 어둠 | size ≥ 2.0이면 화면 조명 반경 −15%, 3.0이면 −30% |

- 적 무구 자동 조준은 어둑시니를 **제외**한다(5.2). 범위 공격은 맞는다(캐논).
- 피해 상한 +0.15/초 **(왜)** 범위 무구 6개가 동시에 맞으면 초당 +60% 이상 커져 학습할 틈도 없이 300%가 된다. 상한이 있으면 "칼질할수록 커진다"를 보고 이해할 시간이 생긴다.

### 15.2 영가 '대신 바라보기'

- 조건: 무당과 어둑시니를 잇는 선분에서 **0.6u 폭 안**에 영가가 1기 이상 있다.
- 배정: 그중 어둑시니에 가장 가까운 영가 1기만 '바라보는 영가'가 된다(동시 1기). 그 영가는 행렬에서 빠져 제자리에서 어둑시니를 향해 돌아선다. 2.0초 뒤 천도한다(넋 +1).
- 바라보는 동안 무당의 시야 원뿔 성장(+0.04)은 **차단**된다(관심을 영가가 대신 받는다).
- 무당이 어둑시니에서 멀어지며 걸으면 행렬이 자연히 그 사이에 놓인다. 등 돌려 걷기와 행렬 바라보기가 같은 동선에서 겹쳐 −0.20/초로 빠르게 줄어든다. **(왜)** 이 문서의 핵심 의도다. "등을 돌리고 걸으면, 내가 구한 넋들이 대신 그것을 바라봐 준다." 입력 없이 전승이 공략법이 된다.
